# PharosPay — RealFi Payroll on Pharos Testnet

## 🚀 Deploy to Vercel

### Option A — Vercel Dashboard (Easiest)
1. Go to https://vercel.com → New Project → Upload Files
2. Drag and drop `index.html` and `vercel.json`
3. Click **Deploy** — done!

### Option B — Vercel CLI
```bash
npm i -g vercel
cd pharospay
vercel --prod
```

### Option C — GitHub + Vercel
1. Push this folder to a GitHub repo
2. Import repo on https://vercel.com/new
3. Framework: **Other** (static HTML)
4. Deploy
